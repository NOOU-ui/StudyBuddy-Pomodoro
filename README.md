**Study Buddy** n'est pas qu'un simple minuteur Pomodoro. C'est un outil conçu pour les étudiants, intégrant une approche basée sur la gestion de l'énergie mentale plutôt que sur la simple gestion du temps.

##  Pourquoi ce projet ?
 J'ai souhaité développer une application qui résout un problème réel : la procrastination et la fatigue décisionnelle pendant les révisions. 

Contrairement aux outils classiques, Study Buddy propose des parcours adaptés :
- **Mode Focus (25m) :** Pour les sessions productives standards.
- **Mode Pause Douce (5m) :** Pour récupérer en cas de fatigue visuelle ou mentale.
- **Mode Mini-Boost (10m) :** Pour vaincre la résistance au démarrage quand la motivation manque.
